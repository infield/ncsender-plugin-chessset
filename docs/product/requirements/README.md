# Requirements

The requirements live in the spec, [`chess-set-creator.md`](../../designs/egm/chess-set-creator.md), §5.1–§5.11. Each item is tagged [C], [P], [O-n] or [v2]. The acceptance criteria are in §9.

[`feature-index.md`](feature-index.md) maps each feature to its spec sections, acceptance criteria, plan phase, open findings and status.

Don't copy requirements into this folder. A new PRD for a future feature can go here. Once a feature is approved for design, its requirements move into the spec through an EGM revision.
