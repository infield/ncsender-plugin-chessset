# Discrepancies awaiting owner decision

When product, discovery or engineering work contradicts the spec, log it here. Don't edit the spec to match. The owner decides each item, and the result goes through an EGM revision.

## Raised by the audience decision (2026-10-30)

**The owner decided that the product is for other ncSender rotary users** (see [`product-decisions.md`](product-decisions.md)). The spec was written for one user and one shop. Each item below is a place where it says so. None of them has been changed.

The options listed are not ranked. *Facts* are quoted from the spec. Where a row says a choice *depends on discovery*, audience research should come before the decision.

| ID | Spec section | Conflict | Options | Decision |

No other user, machine or rotary unit is described. | (a) Rewrite §4 around a target audience once discovery has defined it, keeping Marc as the first user and test site.
